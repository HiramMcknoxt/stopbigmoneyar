# Stop Big Money AR — review build (replica)

A faithful static replica of https://stopbigmoneyar.com, built from the
original site's own source repo (github.com/davwright3/stopbigmoneyar)
reconciled with the live site as fetched November 5, 2026. Original
wording is preserved exactly, including the original's typos.
Parked at: https://hirammcknoxt.github.io/stopbigmoneyar/

Custom domain: a CNAME file for stopbigmoneyar.com is included — Corey
has approved pointing the domain at this GitHub Pages site. The DNS
switch itself is handled separately, and the "Review build / replica"
tag stays on the page until Corey approves the switch as final.

Source snapshots live in the build folder:
~/workspace/stopbigmoneyar-build/sources/ (live-fetch text and links,
plus sources/original-repo/ with the original index.html and styles.css).

Logo: assets/images/stopbigmoneyar_logo2.jpg is the original banner logo
(1144x286, from the original repo). The GitHub connector's snapshot push
cannot carry binary files, so the logo must be added to this repo by web
upload (GitHub → Add file → Upload files → assets/images/) if it is not
already present; the text snapshot push deliberately excludes it.
